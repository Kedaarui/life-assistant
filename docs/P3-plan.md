# P3 计划 · 记忆与画像

> 状态：**未开始**。P0–P2 已完成；本文只是留档，方便之后继续。

## 目标

从「检索原始事件」升级为「AI 真正理解你」：

- 从事件记录中提炼**长期记忆**（人物、偏好、目标、价值观、反复出现的模式）
- 生成可审阅的**用户画像**（用户画像）
- 通过夜间任务持续更新，而不是每次临时总结
- 对话时注入画像与已确认记忆，仍能引用回原文

## 数据（表已在 P0 建好）

- `memories`：类型、主体、谓词、客体、置信度、有效期、来源 entry_ids、`superseded_by`、状态
- `profile_snapshots`：周期、摘要、版本
- `summaries`：日/周/月摘要
- `jobs`：任务类型、状态、payload、重试次数、错误

## P3.1 记忆抽取

1. 新增 `lib/modules/memory/extractor.ts`
   - 输入：一条事件（标题 + 正文 + 时间精度 + 标签）
   - 输出：严格 JSON 数组，字段：
     ```json
     {
       "type": "person|preference|goal|value|event|pattern|relationship",
       "subject": "我",
       "predicate": "喜欢",
       "object": "清晨写作",
       "confidence": 0.85,
       "evidence": "原文中的一句依据",
       "valid_from": "2026-10-28"
     }
     ```
   - 使用 `LLM_CHAT_MODEL` 或更便宜的抽取模型；JSON Schema 校验，失败重试一次。
   - **跳过 `local_only` 事件**。
2. 去重与冲突：
   - 规范化键：`type + subject + predicate + object` 的哈希
   - 已存在且未过期 → 提高置信度、追加来源
   - 冲突 → 旧记忆写 `superseded_by`，保留演进链，不静默删除
   - 新记忆默认 `candidate`；高置信度 + 多次来源可自动 `confirmed`
3. 触发方式：
   - 保存事件后异步抽取（P3 先同步或简单后台队列）
   - 夜间批量补抽历史事件

## P3.2 用户画像

1. `lib/modules/memory/profile.ts`
   - 基于已确认记忆 + 最近 30 天事件生成「现在的你是谁」摘要
   - 分节：近期状态、长期主题、重要人物、目标与价值观、正在变化的方面
   - 每次生成新版本，不覆盖旧版本
2. 对话注入：
   - 系统提示中增加稳定画像块（放在事件片段之前）
   - 引用仍用 `[[E1]]`，画像中的结论需要能追溯到记忆/原文（后续可加 `[[M1]]`）
3. 用户可编辑：
   - 画像页支持直接修改文字，修改后作为新的 version

## P3.3 夜间任务与摘要

1. `instrumentation.ts` + `node-cron`（单例 + 全局锁）
2. 每晚 03:17：
   - 补齐未索引/未向量化的事件
   - 对新事件抽取记忆并合并
   - 生成当日摘要
   - 必要时刷新画像
3. 每周日：
   - 周回顾
   - 画像快照
4. `jobs` 表驱动，失败重试 3 次，记录错误
5. 设置页提供「立即运行维护任务」和任务状态

## P3.4 UI

- `/profile`：用户画像
  - 按类型分组（人物、偏好、目标、价值观、模式）
  - 每条显示置信度、来源事件、状态
  - 操作：确认 / 否认 / 编辑 / 删除
  - 冲突记忆显示演进链
- `/insights` 或首页卡片：
  - 今日摘要、本周回顾、情绪/主题趋势
- 设置页：
  - 抽取模型、任务状态、上次运行时间、手动触发
  - 画像版本列表

## 对话集成

- 提示词顺序：
  1. 系统角色与规则
  2. 用户画像（稳定）
  3. 已确认长期记忆（相关 Top-N）
  4. 检索到的事件片段（带 E 编号）
  5. 最近对话
  6. 当前问题
- 画像与记忆必须可关闭/删除；用户否认后下一次对话不再使用。
- `local_only` 事件及其派生记忆永不注入。

## 测试

- 抽取 JSON 校验与重试
- 去重、冲突、`superseded_by` 链
- `local_only` 不抽取、不注入
- 画像注入后对话仍能引用原文
- 夜间任务幂等、失败重试、手动触发
- 记忆审阅页确认/否认/删除后画像刷新
